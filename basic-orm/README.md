# Basic ORM Example

Laravel-style models with `@bunary/orm` on [Drizzle](https://orm.drizzle.team): Drizzle SQLite
tables, `defineModel(db, table)`, drizzle-kit migrations, and the database booted through
`@bunary/core` with the orm's `ormProvider`.

## Versions

| Package | Version |
| --- | --- |
| `@bunary/core` | `^0.4.0` |
| `@bunary/orm` | `^0.4.0` |
| `drizzle-orm` | `^0.45.0` (peer dependency of the orm) |
| `drizzle-kit` | `^0.31.0` (dev, migrations) |

Requires Bun ≥ 1.4.0.

## Quick start

```bash
bun install
bun run db:setup   # create example.sqlite: apply migrations, seed sample data
bun run start      # run the example (it re-runs the setup first)
```

## Scripts

| Script | Does |
| --- | --- |
| `bun run start` | Recreate `example.sqlite` and run every demo step |
| `bun run dev` | Same, with `--watch` |
| `bun run db:setup` | Delete `example.sqlite`, apply the migrations in `drizzle/`, seed the sample data |
| `bun run db:generate` | Write a new SQL migration in `drizzle/` after you change `src/db/schema.ts` (drizzle-kit) |
| `bun test` | Run the tests (in-memory SQLite, migrated and seeded per test) |
| `bun run typecheck` | `tsc --noEmit` |

`example.sqlite` is generated by `db:setup` and git-ignored; never edit it by hand.

## What it shows

| Feature | Where |
| --- | --- |
| Drizzle tables and `relations()` (`drizzle-orm/sqlite-core`) | `src/db/schema.ts` |
| Migrations generated by drizzle-kit, applied with `migrate()` from `drizzle-orm/bun-sqlite/migrator` | `drizzle.config.ts`, `drizzle/`, `src/db/database.ts` |
| `createApp()` + `ormProvider()` building the db from the `database` config key | `src/db/database.ts` |
| `defineModel(db, table, { hidden, events, scopes, softDeletes })` | `src/models.ts` |
| `find()`, `findOrFail()` / `ModelNotFoundError`, `where(cond).get()` / `.first()`, `query()` | `src/index.ts` steps 1–4 |
| `create()`, dirty tracking (`isDirty()`, `getDirty()`), `save()`, `refresh()`, `delete()` | steps 5–8 |
| Named scopes: `User.active().olderThan(25)`, `Post.published()` | step 9 |
| Soft deletes: `delete()`, `trashed()`, `withTrashed()`, `onlyTrashed()`, `restore()` | step 10 |
| Eager loading: `User.with({ posts: Post })`, `Post.with({ author: User })` | step 11 |
| Hidden column (`password`) and a `creating` event that hashes it | `src/models.ts` |

### Schema and models

```typescript
// src/db/schema.ts
export const users = sqliteTable("users", {
  id: integer().primaryKey({ autoIncrement: true }),
  name: text().notNull(),
  email: text().notNull().unique(),
  password: text().notNull(),
  age: integer(),
  active: integer({ mode: "boolean" }).notNull().default(true),
  createdAt: integer("created_at", { mode: "timestamp_ms" }).notNull().$defaultFn(() => new Date()),
});

export const posts = sqliteTable("posts", {
  id: integer().primaryKey({ autoIncrement: true }),
  authorId: integer("author_id").notNull().references(() => users.id),
  title: text().notNull(),
  body: text(),
  published: integer({ mode: "boolean" }).notNull().default(false),
  deletedAt: integer("deleted_at", { mode: "timestamp_ms" }),
});
// + usersRelations (posts: many) and postsRelations (author: one)
```

```typescript
// src/models.ts
const User = defineModel(db, users, {
  hidden: ["password"],
  events: { creating: async (values) => { values.password = await Bun.password.hash(values.password); } },
  scopes: {
    active: (q) => q.where(eq(users.active, true)),
    olderThan: (q, age: number) => q.where(gt(users.age, age)),
  },
});

const Post = defineModel(db, posts, {
  softDeletes: true,
  scopes: { published: (q) => q.where(eq(posts.published, true)) },
});
```

Models take the database explicitly, so `defineModels(db)` builds them per database: the example
passes the `example.sqlite` database, the tests an in-memory one.

### Booting the database

```typescript
// src/db/database.ts
const app = await createApp({
  config: { app: { name: "Basic ORM Example" }, database: { dialect: "sqlite", path } },
  providers: [ormProvider({ schema })],
}).boot();

const db = app.get(DatabaseToken) as AppDatabase;
migrate(db, { migrationsFolder });
```

### Using the models

```typescript
const user = await User.findOrFail(1);
user.age = 26;
user.getDirty();          // { age: 26 }
await user.save();        // UPDATE "users" SET "age" = ? WHERE "users"."id" = ?

await User.active().olderThan(25).get();
await User.where(eq(users.email, "jane@example.com")).first();
await User.query().orderBy(desc(users.age)).limit(2); // plain Drizzle for ordering/limits

const draft = await Post.findOrFail(4);
await draft.delete();     // sets deleted_at
await Post.onlyTrashed().get();
await draft.restore();

const john = await User.with({ posts: Post }).findOrFail(1);
john.posts;               // Post instances
JSON.stringify(john);     // includes posts, never password
```

## Project structure

```
basic-orm/
├── drizzle.config.ts      # drizzle-kit config
├── drizzle/               # generated SQL migrations (committed)
├── src/
│   ├── db/
│   │   ├── schema.ts      # Drizzle tables and relations
│   │   ├── database.ts    # createApp + ormProvider + migrate()
│   │   └── setup.ts       # bun run db:setup
│   ├── models.ts          # defineModel() for User and Post
│   ├── seed.ts            # sample data
│   └── index.ts           # the example
└── tests/                 # bun test
```

## Changing the schema

1. Edit `src/db/schema.ts`.
2. `bun run db:generate` to write the migration into `drizzle/`.
3. `bun run db:setup` to rebuild `example.sqlite`.
